# honkai-guide

## Project setup

Install Node.js

To install dependencies, run:

```
npm install
```

### Compiles and hot-reloads for development

```
npm run dev
```

### Compiles and minifies for production

```
npm run build
```

### Runs the unit tests

```
npm run test
```

Or in watch mode, re-running the affected tests as you edit:

```
npm run test:watch
```

The suite lives in `src/tests/` and runs on [Vitest](https://vitest.dev/).

### Type-checks the project

```
npm run type-check
```

### Lints and fixes files

```
npm run lint
```

### Locally previews the production build

```
npm run preview
```

### Customize configuration

See the [Vite Configuration Reference](https://vitejs.dev/config/).
